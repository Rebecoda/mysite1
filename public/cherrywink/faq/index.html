For the prototype, yes — as a narrative placeholder. In the live store this section would reflect actual shipping zones and transit estimates.

Can I really place an order?

Not yet. The cart is functional in local storage, but checkout is intentionally non-functional in this phase-one demo.

How would returns work?

The current copy is placeholder only. Once the store policy is clear, this page becomes the trust layer that supports conversion.

Why include FAQ so early?

Because a believable independent store needs more than product cards. It needs confidence-building information architecture.
